# 项目简报：exsport

状态：第 2 版，待用户确认
日期：2026-09-23

## 1. 背景与问题

要做的是一个叫 **exsport** 的网站，主题是介绍各种各样的运动。

目前想解决的是两类人的问题：

- 已经在运动的人：想快速找某一项运动的规则、入门方法、装备、训练要点。
- 想运动但还没动起来的人：不知道从哪开始、选什么项目、需要准备什么。

后端目标是把网站的访问量做起来。变现不着急：第一版不做任何变现功能，只在结构上留出以后可扩展的位置。

名称含义：「exsport」= **expert + sport**，心智是「专家级的运动指南」，slogan 与视觉都围绕它展开。

## 2. 目标与成功指标

核心目标：把人吸引进来看运动内容，并留住一部分人（注册、收藏、评论）。

成功指标（演示版阶段，均为假设，可调整）：

- 10 项运动的详情页全部可访问、无死链。
- 收藏按钮的点击率、注册引导按钮的点击率可被记录。
- 移动端打开无横向滚动、正文可读。

最低可接受成功：一个能公开访问、4 类页面齐全、手机端能正常浏览的演示站点。

什么算失败：只有一页静态介绍，点不进任何运动详情。

## 3. 目标用户与核心场景

用户一：运动爱好者
场景：想看某个项目的规则、训练要点、装备清单，频率可能每周几次。

用户二：想动但还没行动的人
场景：刷到网站，想知道「我这个情况适合练什么」，第一次访问需要被引导。

谁买单：后端靠流量变现，具体客户类型未定。

最痛的 3 点（假设）：

1. 不知道从哪一项运动开始。
2. 每项运动的信息散落在各处，规则和入门门槛不清楚。
3. 看完之后没有下一步动作。

## 4. 范围与优先级

MVP（第一版可点击演示版）：

- 4 类页面：首页、运动分类页、运动详情页、关于页。
- 覆盖 10 项热度最高的运动（待你点头）：跑步、篮球、足球、羽毛球、乒乓球、游泳、健身、瑜伽、骑行、徒步登山。备选替换：滑雪、网球。
- 每项运动包含：简介、规则、入门步骤、装备清单、训练要点、视频嵌入位。
- 收藏与评论用演示数据展示，收藏结果暂存在浏览器本地。
- 新增功能（你的建议）：伤痛地图——3D 人体 + 痛点热点，悬停看原因、点击看完整原因与有益运动。
- 架构调整：首页本身就是 3D 人体伤痛地图，全站运动从人体部位展开；不再单独设 /body 页面。

P0（必须有）：

- 首页（含吸引人的首屏与运动分类入口）
- 分类页（10 项运动的总览与筛选/分组）
- 详情页（10 个，结构统一）
- 关于页
- 响应式（手机端可用）

P1（第二版）：

- 真实注册、登录、账号中心
- 收藏持久化到账号
- 评论可提交
- 站内搜索
- SEO 基础优化、暗色模式

P2（以后）：

- 视频专区、训练计划、社区动态、装备推荐与带货位
- 变现模块（广告位、联盟链接）

明确不做（第一版）：

- 不做真实支付
- 不做课程售卖
- 不做用户自己上传内容
- 不做多语言
- 不做手机 App

## 5. 核心用户流程

1. 进入首页 → 看到一句话定位与运动入口。
2. 进入分类页 → 浏览 10 项运动，按热度或类型挑选。
3. 进入详情页 → 看简介、规则、入门步骤、装备、视频。
4. 产生动作 → 点收藏、点评论、点注册引导。
5. 演示版里收藏与评论先落地为本地状态，注册入口记录点击。

第一次使用最需要看到：这个网站是干什么的，以及「我想动起来该怎么选」。

## 6. 功能需求

- 首页：Hero 定位语、运动分类入口、适合新手的推荐、网站价值说明。
- 分类页：10 项运动的卡片列表、分组或筛选、排序。
- 详情页：统一的区块结构，视频嵌入位，收藏与评论按钮。
- 关于页：网站初衷、内容来源说明、联系方式位。
- 全局：顶部导航、页脚、响应式布局。
- 演示交互：收藏（本地存储）、评论（模拟数据）、注册引导点击。

## 7. 非功能需求

- 性能：静态资源轻量，首屏快速可见；视频用嵌入，不做自托管。
- 可用性：手机优先适配，触屏按钮尺寸足够。
- 无障碍：图片带替代文本，正文对比度达标。
- 合规：不使用未授权的图片与视频；引用来源需标注。
- 隐私：演示版不收集真实个人信息；正式版接入注册时需单独确认隐私政策。

## 8. 约束与依赖

- 内容来源：用 AI 生成底稿，由你审校后定稿。
- 素材：第一版一律用占位素材（渐变、几何图形、占位图框架），不依赖真实照片。
- 技术栈：已确认用 React 等框架，具体组合建议 React + Vite + React Router + Tailwind CSS（待你确认）。
- 语言与地区：面向中国用户，简体中文。
- 部署与域名：你已有想法，但第一版不急着上线，先本地跑通。

## 9. 风险与假设

假设（属于推断，需你确认）：

- 视觉风格暂缓决定，先给 2 到 3 套配色方向再选。
- 内容形态为图文为主 + 视频嵌入位。
- 网站语言为简体中文，面向中国用户。
- 变现不着急，第一版不做变现模块，只预留以后可插入的位置。
- 第一版走「可点击演示版」，因此注册、评论用演示数据处理。

风险：

- 变现方式以后才定，后期可能改动页面结构与推荐位（中等）。
- 需要注册与收藏，若第一版就做真实后端，工期和成本会明显上升（高）。
- AI 生成的运动内容存在事实错误风险，必须人工审校（高）。
- 图片素材未定，直接影响视觉完成度（中等）。
